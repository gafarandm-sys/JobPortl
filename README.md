# JobPortal

A job recruitment website built with ASP.NET Web Forms, C#, and SQL
Server.

## Project overview

JobPortal is an academic web application project intended to demonstrate
the main workflow of a job recruitment website.

## Technologies

-   ASP.NET Web Forms
-   C#
-   SQL Server
-   HTML and CSS

## Main features

The project includes pages for browsing job listings, viewing job
details, posting and managing jobs, viewing applications, and managing a
user profile. It also includes account registration and login pages.

## Project status

This repository is being prepared as a portfolio project. Before using
it in a public or production environment, review and update the database
connection settings, verify authorization checks, and replace any
insecure password-handling logic with secure password hashing.

## Running the project

The project was developed as an ASP.NET Web Forms application. To run
it, open the solution in a compatible version of Visual Studio,
configure the SQL Server database and connection string for your
environment, and then run the application.

A database export file may be provided separately. Do not publish real
user data, credentials, or private connection details.

## Note

This is a portfolio/learning project and should not be treated as
production-ready until its security and configuration have been
reviewed.
